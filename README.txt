Task Tracker — PWA-пакет

Файлы: index.html (приложение), manifest.webmanifest, sw.js, icons/.
Установка на экран телефона работает только при открытии по HTTPS (или http://localhost).

Как разместить (любой вариант, все файлы кладутся в одну папку):
 1. Netlify Drop: netlify.com/drop → перетащить папку целиком → получить ссылку https://...
 2. GitHub Pages: загрузить файлы в репозиторий → Settings → Pages.
 3. Любой хостинг: загрузить содержимое папки в корень сайта.

Установка:
 iPhone (Safari): открыть ссылку → кнопка «Поделиться» → «На экран Домой» → «Добавить».
 Android (Chrome): открыть ссылку → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).

Данные хранятся в браузере устройства (localStorage) отдельно для каждого адреса и устройства.
Синхронизации между телефоном и компьютером нет. Перенос: Настройки → Экспорт в JSON → Импорт на другом устройстве.
